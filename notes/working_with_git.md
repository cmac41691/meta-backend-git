# Working with Git

## Purpose

Git is a distributed version control system used to track changes in files and projects over time.

---

## Why Git Exists

Git helps developers:

* Track project history
* Recover previous versions
* Collaborate with other developers
* Manage changes safely
* Experiment without losing work

---

## Core Concept

Without Git:

File
↓
Edit
↓
Overwrite
↓
Lose History

With Git:

File
↓
Edit
↓
Commit
↓
History Preserved

## Git vs GitHub

# Git

Version Control System

# GitHub

Platform that hosts Git repositories

Example:

git commit

Works locally without internet.

git push

Sends commits to GitHub.

---

## Commands

### git status

Purpose:
Shows the current state of the repository.

### git add

Purpose:
Stages changes for the next commit.

### git commit

Purpose:
Saves a snapshot of staged changes.

### git push

Purpose:
Uploads commits to a remote repository.

### git pull

Purpose:
Downloads changes from a remote repository.

Git allows developers to safely track, organize, and manage project history. It provides a structured workflow for building software individually and as part of a team.
